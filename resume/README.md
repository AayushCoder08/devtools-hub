# JobReady Resume Maker

A lightweight, responsive resume builder made with plain HTML, CSS and JavaScript.

## Features
- Live resume preview
- Personal details, summary, education, skills, projects/experience, certifications and languages
- Three styles: Classic ATS, Modern and Compact
- Print dialog to save the resume as PDF
- Responsive layout for desktop and mobile
- Resume data is processed in the browser; this demo does not upload it to a server

## Run on Windows
1. Extract `JobReady-Resume-Maker.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in Chrome, Edge or Firefox.
4. Fill in your details and choose a template.
5. Click **Download PDF**.
6. In the print dialog, choose **Save as PDF** as the destination, then click **Save**.

No Node.js, server, or package installation is required.

## Notes
- The project uses a Google Fonts import for typography when internet is available; system fonts are used as fallbacks.
- For the cleanest PDF, use A4 paper and default scale in the browser print dialog.
- Review all details before sending your resume. Do not add experience or qualifications you do not have.
